# Lucho Dona — Arquitecto

Sitio personal de Luciano Dona: arquitectura sustentable y eficiencia energética.

SPA estática (HTML/CSS/JS vanilla, sin build): un solo `index.html` con navegación por anclas y scroll suave. Contenido e imágenes tomados de su sitio de referencia en Canva.

## Desarrollo local

Abrir `index.html` en el navegador, o servirlo:

```sh
npx serve .
```

## Deploy

Deployado en Vercel como sitio estático (sin configuración especial).
